# AURELIA — Live Beyond Walls

A cinematic single-page luxury-house experience. A night-lit mansion with glowing
windows; hover or click a window — or simply scroll — and the camera flies **into**
that window and you arrive inside the room. Scrolling carries you room to room:
Living → Bedroom → Cinema → Kitchen → Spa.

- Pure HTML/CSS + GSAP ScrollTrigger (scroll-scrubbed timeline, window zoom + cross-fade).
- Imagery generated with WaveSpeed (Seedream), unified art direction so interiors match the house.

## Run locally
```
python3 -m http.server 8000
# open http://localhost:8000
```
